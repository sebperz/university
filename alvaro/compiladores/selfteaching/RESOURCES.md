# Compilers Resources

## Knowledge

- [Book (free online): _Crafting Interpreters_ — Robert Nystrom](https://craftinginterpreters.com/)
  The single best match for this mission. Project-based: you build a full interpreter for a scripting language from `main()` up. Use for: every phase as we reach it — lexing (ch. 4), parsing (ch. 6), evaluation (ch. 7), and beyond. We mirror its structure in our own Python project.
- [Book: _Compilers: Principles, Techniques, and Tools_ (2nd ed.) — Aho, Lam, Sethi & Ullman](https://www.pearson.com/en-us/subject-catalog/p/compilers-principles-techniques-and-tools/P200000003127)
  "The Dragon Book" — the formal reference my course cites. Use for: precise definitions of grammars, ambiguity, and parsing theory when I need rigor to answer course exercises.
- [Course material: "Actividad 1" PDF in the course folder](../Actividad%201.%20Fundamentos%20de%20Compiladores%20y%20Análisis%20Léxico-Sintáctico.pdf)
  The actual syllabus anchor: compiler phases, regexes, DFAs, ambiguity. Use for: knowing exactly what the course will test.
- [Video lectures: Stanford CS143 — Compilers (Alex Aiken)](https://www.youtube.com/playlist?list=PLDcmCgguL9rxPoVn2oTXDGGplV2LdpV0r)
  Clear university lectures on lexing, parsing, and semantic analysis. Use for: a second explanation of anything the course material feels fuzzy on.
- [Tutorial: _Let's Build a Compiler_ — Jack Crenshaw](https://compilers.iecc.com/crenshaw/)
  Old (1988) but a beautifully readable walkthrough of a hand-written recursive-descent compiler. Use for: intuition about how a real compiler is structured with almost no machinery.
