La imagen mental

Subes la montaña desde el texto crudo hasta el significado (análisis); la bajas desde el significado hasta el código (síntesis). El análisis no ejecuta nada: solo entiende y comprueba.

Qué detecta cada fase

FaseEntrada → SalidaDetectaNO detecta
Léxico caracteres → tokens símbolos mal formados gramática, tipos
Sintáctico tokens → árbol estructura inválida, paréntesis faltante tipos, nombres no declarados
Semántico árbol → árbol anotado tipos incompatibles, variable no declarada eficiencia

Las cuatro trampas que más fallan

  1. "El léxico verifica la gramática" → FALSO. Eso es el sintáctico.
  2. "El semántico construye el árbol" → FALSO. Lo construye el sintáctico; el semántico lo anota (tipos, ámbitos).
  3. "La tabla de símbolos es solo del léxico" → FALSO. La usan léxico, sintáctico, semántico y también optimización/generación.
  4. "El front-end incluye la optimización" → FALSO. La optimización va después del análisis.

La tabla de símbolos

Guarda, por cada identificador: nombre, tipo, dirección de memoria y ámbito. Permite verificar el uso correcto de los identificadores. Interactúa con casi todas las fases.
