# Compiladores Resources

## Knowledge

- [Libro online: _Crafting Interpreters_, cap. 2 "A Map of the Territory" — Robert Nystrom](https://craftinginterpreters.com/a-map-of-the-territory.html)
  El mejor resumen gratuito del recorrido completo del compilador (scanning, parsing, análisis estático, IR, optimización, generación de código, VM, JIT, transpiladores). Usar para: el mapa mental de las fases y cómo se conectan.
- [Wikipedia ES: Compilador](https://es.wikipedia.org/wiki/Compilador)
  Terminología en español alineada con el curso: fases de análisis y síntesis, front-end/back-end, tipos de compiladores (cruzado, optimizador, una/varias pasadas, JIT), tabla de símbolos, árbol sintáctico, código intermedio. Usar para: vocabulario exacto del examen y definiciones.
- [Wikipedia EN: Lexical analysis](https://en.wikipedia.org/wiki/Lexical_analysis)
  Tokens, lexemas, patrón, scanner, maximal munch, lexer hack. Usar para: todo lo léxico.
- [Wikipedia EN: Parsing](https://en.wikipedia.org/wiki/Parsing)
  Parse tree vs AST, errores sintácticos, gramáticas libres de contexto. Usar para: análisis sintáctico.
- [Wikipedia EN: Semantic analysis (compilers)](https://en.wikipedia.org/wiki/Semantic_analysis_\(compilers\))
  Verificación de tipos, resolución de nombres, tabla de símbolos. Usar para: análisis semántico.
- [Wikipedia EN: Just-in-time compilation](https://en.wikipedia.org/wiki/Just-in-time_compilation) · [Cross compiler](https://en.wikipedia.org/wiki/Cross_compiler) · [Source-to-source compiler](https://en.wikipedia.org/wiki/Source-to-source_compiler)
  Usar para: tipos de compiladores y transpiladores, con bajo riesgo de ambigüedad.
- [Libro: _Compilers: Principles, Techniques, and Tools_ (Dragon Book) — Aho, Lam, Sethi, Ullman]
  Referencia canónica del campo. Usar para: resolver cualquier afirmación en disputa; es la fuente que siguen casi todos los cursos.

## Wisdom (Communities)

- [r/Compilers](https://www.reddit.com/r/Compilers/)
  Subreddit técnico y con buena moderación. Usar para: entender por qué una técnica existe en la práctica, contrastar intuiciones.
- [Stack Overflow — etiqueta `compiler-construction`](https://stackoverflow.com/questions/tagged/compiler-construction)
  Preguntas concretas sobre fases y terminología. Usar para: dudas puntuales bien acotadas.
- [Computer Science Stack Exchange](https://cs.stackexchange.com/)
  Para preguntas más teóricas (gramáticas, autómatas). Usar con moderación: el examen es conceptual.
