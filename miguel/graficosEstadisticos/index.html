Guía rápida — Chart.js

1. Incluir la librería

Agrega el script de Chart.js en el <head> desde un CDN:

<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.7/dist/chart.umd.min.js"></script>

2. Crear un <canvas>

Cada gráfico necesita su propio elemento <canvas> con un id único:

<canvas id="chart-ingresantes"></canvas>

3. Preparar los datos

Los datos se organizan en un array de objetos. Cada objeto tiene la carrera, el año y los valores de cada métrica:

const datos = [
  { c: "Ing. Sistemas",  a: 2010, i: 180, g: 130, d: 22 },
  { c: "Ing. Mecánica",  a: 2010, i: 90,  g: 65,  d: 10 },
  { c: "Ing. Industrial", a: 2010, i: 110, g: 80,  d: 13 },
  // ...
];

4. Configurar y crear el gráfico

Chart.js recibe 3 cosas: el elemento canvas, el tipo de gráfico y un objeto con labels, datasets y options:

new Chart(document.getElementById('chart-ingresantes'), {
  type: 'line',
  data: {
    labels: years,                    // [2010, 2011, ..., 2020]
    datasets: [                       // una serie por carrera
      { label: 'Ing. Sistemas',  data: [180, 195, ...], borderColor: '#4A90D9' },
      { label: 'Ing. Mecánica',  data: [90,  95,  ...], borderColor: '#E67E22' },
      { label: 'Ing. Industrial', data: [110, 115, ...], borderColor: '#27AE60' },
    ]
  },
  options: {
    responsive: true,
    plugins: { legend: { position: 'bottom' } },
    scales: {
      x: { title: { display: true, text: 'Año' } },
      y: { beginAtZero: true }
    }
  }
});

Resumen: con esos 4 pasos (CDN, canvas, datos, new Chart(...)) ya tienes gráficos interactivos listos. Chart.js soporta line, bar, pie, doughnut, radar y más — solo cambia type y ajusta los datos.
