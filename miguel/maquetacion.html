ETIQUETA: <header> ... </header>

Documentacion Tecnica: Etiqueta HEADER

Definicion: Elemento de bloque que representa contenido introductorio o de navegacion auxiliar. Tipicamente contiene titulos, subtitulos, logotipos, formularios de busqueda o datos de autor.

Ubicacion en documento: Puede anidarse como hijo directo de <body> (encabezado global) o dentro de <article> y <section> (encabezados contextuales).

Restricciones: No debe descender de <footer>, <address> u otro <header>.

Etiquetas de apertura y cierre:

<header> ...contenido... </header>
ETIQUETA: <nav> ... </nav>

Documentacion Tecnica: Etiqueta NAV

Definicion: Seccion de navegacion principal que enlaza a otras paginas o secciones dentro del documento actual. Exclusiva para bloques de enlaces de navegacion significativos.

Contenido permitido: Elementos de flujo. Tipicamente listas ordenadas (<ol>) o desordenadas (<ul>) conteniendo elementos <li> con enlaces <a>.

Criterio de uso: No todos los grupos de enlaces requieren <nav>. Reservar para navegacion principal, tablas de contenido, indices y menus de seccion.

Estructura:

<nav>
    <ul>
        <li><a href="#seccion1">Seccion 1</a></li>
        <li><a href="#seccion2">Seccion 2</a></li>
    </ul>
</nav>

Implementacion funcional:

  • Navegar a MAIN
  • Navegar a SECTION
  • Navegar a ARTICLE
ETIQUETA: <main> ... </main>

Documentacion Tecnica: Etiqueta MAIN

Definicion: Contenido dominante del <body> del documento. Representa el contenido unico y no repetitivo de la pagina, excluyendo bloques que se repiten en multiples documentos (navegacion, pies de pagina, barras laterales, logos).

Restricciones formales:

  • Debe ser unico en el documento
  • No debe ser descendiente de <article>, <aside>, <footer>, <header> o <nav>
  • No debe tener atributo hidden

Accesibilidad: Los lectores de pantalla pueden utilizar <main> como punto de referencia para saltar directamente al contenido esencial (atajo de teclado tipico: tecla "M").

Estructura:

<main>
    [Contenido unico y especifico de la pagina]
</main>
ETIQUETA: <section> ... </section>

Documentacion Tecnica: Etiqueta SECTION

Definicion: Contenedor generico para agrupar contenido tematicamente relacionado. Representa una seccion generica de un documento o aplicacion.

Requisito obligatorio: Cada <section> debe contener al menos un encabezado (<h1>-<h6>) como hijo directo o indirecto que identifique la tematica de la seccion.

Diferenciacion con <article>: <section> agrupa contenido tematico; <article> agrupa contenido autocontenido. Un <article> puede contener multiples <section>, y viceversa.

Estructura:

<section>
    <h2>Titulo de la seccion</h2>
    [Contenido relacionado tematicamente]
</section>
ETIQUETA: <article> ... </article>

Documentacion Tecnica: Etiqueta ARTICLE

Definicion: Composicion autocontenida en un documento, pagina, aplicacion o sitio, destinada a ser distribuida o reutilizada de forma independiente.

Casos de uso tipicos:

  • Entradas de foro
  • Articulos de revista o periodico
  • Entradas de blog
  • Tarjetas de producto
  • Comentarios enviados por usuarios
  • Widgets interactivos

Autonomia semantica: El contenido de un <article> debe tener sentido completo incluso cuando se extrae del contexto del documento principal.

Estructura:

<article>
    <header>
        <h1>Titulo del articulo</h1>
    </header>
    [Contenido autocontenido]
    <footer>Metadatos del articulo</footer>
</article>
ETIQUETA: <aside> ... </aside>

Documentacion Tecnica: Etiqueta ASIDE

Definicion: Representa una seccion de una pagina que consiste en contenido tangencialmente relacionado con el contenido que lo rodea, pero que podria considerarse separado de ese contenido.

Posicionamiento: Frecuentemente presentado como barras laterales o llamadas destacadas. Semanticamente representa contenido complementario no esencial para la comprension del documento principal.

Tipos de contenido apropiados:

  • Barras laterales explicativas
  • Publicidad
  • Grupos de enlaces de navegacion auxiliar
  • Perfiles de autor
  • Datos relacionados
  • Citas extensas (blockquotes contextuales)

Relacion con <main>: No debe estar anidado dentro de <main> cuando representa contenido tangencial global. Puede anidarse dentro de <article> para contenido relacionado especifico del articulo.

Estructura:

<aside>
    [Contenido complementario]
</aside>

Nota de implementacion: En este documento, <aside> se posiciona lateralmente mediante estructura de tabla HTML, demostrando visualmente su naturaleza de contenido tangencial sin uso de hojas de estilo CSS.
ETIQUETA: <footer> ... </footer>

Documentacion Tecnica: Etiqueta FOOTER

Definicion: Elemento que representa el pie de pagina para su seccion de contenido raiz mas cercana o para el elemento <body>. Tipicamente contiene informacion sobre el autor, enlaces a documentos relacionados, datos de copyright o informacion de licencia.

Ambito de aplicacion: Puede aplicarse a <body> (pie global), <article> (metadatos del articulo), <section> (metadatos de seccion), entre otros.

Contenido tipico:

  • Informacion de autoría
  • Enlaces a terminos legales
  • Informacion de contacto
  • Mapas del sitio
  • Enlaces a redes sociales
  • Documentos relacionados

Restricciones: No debe ser descendiente de <header>, <address> u otro <footer>.

Estructura:

<footer>
    <p>&copy; [Año] [Entidad]. Todos los derechos reservados.</p>
    [Enlaces relacionados o metadatos]
</footer>
