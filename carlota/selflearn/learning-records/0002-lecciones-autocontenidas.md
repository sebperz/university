# Las lecciones deben ser autocontenidas y generales

Feedback del usuario tras leer las lecciones 1-2: no definían suficientes términos y las secciones "Ejercicio para tu entrega" las hacían parecer guiones de tarea, no lecciones. Implicación para futuras lecciones: (1) cada término —incluidas siglas en inglés como RTO, RPO, p99, TTL— se define dentro del documento con su tabla/diccionario; (2) las lecciones son documentos generales sobre el tema, con el Caso C solo como ejemplo; los ejercicios guiados por entregable desaparecen (los quizzes interactivos se conservan).
