Métricas de clasificación

Exactitud, precisión, recall, FNR, FPR, F1 y ROC-AUC no son sinónimos. Cada una responde una pregunta distinta y esconde un daño distinto. Esta hoja sirve para leer el Documento A y el Documento B sin confundirlas.

La idea en una frase

Un modelo puede tener un buen promedio y, al mismo tiempo, dejar fuera a las personas que más necesitan ayuda. Las métricas globales no lo muestran; las métricas desagregadas sí.

La matriz de confusión

Todo empieza aquí. Para un problema binario, cada paciente cae en una de cuatro celdas según lo que realmente ocurrió y lo que el modelo predijo.

El modelo dice: alto riesgo El modelo dice: bajo riesgo
El paciente sí tendrá una complicación Verdadero positivo (TP)
Se detecta y se actúa.		 Falso negativo (FN)
Se deja pasar. Es el error más grave en un tamizaje.
El paciente no tendrá una complicación Falso positivo (FP)
Alerta innecesaria, recurso gastado, posible estigma.		 Verdadero negativo (TN)
Se descarta correctamente.

La matriz se lee por filas: primero la realidad, después la predicción. Si el dossier no reporta esta tabla, no se pueden reconstruir todas las métricas con seguridad.

Las fórmulas

Exactitud   = (TP + TN) / (TP + TN + FP + FN)
Precisión   = TP / (TP + FP)
Recall      = TP / (TP + FN)
FNR         = FN / (TP + FN) = 1 - Recall
FPR         = FP / (FP + TN) = 1 - Especificidad
Especificidad = TN / (TN + FP)
F1          = 2 × (Precisión × Recall) / (Precisión + Recall)

Qué pregunta responde cada métrica

Métrica La pregunta que responde Qué puede esconder
Exactitud (accuracy) De todos los casos, ¿qué proporción acertó? El desbalance de clases. Un modelo que diga "sin riesgo" a todos puede tener 85% de exactitud si solo 15% tiene la condición.
Precisión (valor predictivo positivo) De los que marqué como positivos, ¿cuántos lo eran? Los falsos negativos. Un modelo puede ser muy preciso y dejar pasar a muchos enfermos.
Recall (sensibilidad) De los que realmente eran positivos, ¿cuántos detecté? Los falsos positivos. Se puede subir el recall marcando a casi todos, a costa de más alertas innecesarias.
FNR (tasa de falsos negativos) De los que realmente eran positivos, ¿qué proporción dejé pasar? El volumen absoluto. Un 42% suena abstracto hasta que se convierte en 420 de cada 1.000.
FPR (tasa de falsos positivos) De los que realmente eran negativos, ¿a qué proporción marqué como positivos? El costo de las falsas alarmas y el posible estigma.
F1 ¿Cómo se combinan precisión y recall en un solo número? Cuál de las dos es baja y cuánto cuesta cada tipo de error. Es una media armónica, no una medida de equidad.
ROC-AUC ¿Qué tan bien ordena el modelo a un positivo por encima de un negativo? La calibración, el umbral elegido y el desempeño por subgrupo. Un AUC alto no garantiza que el modelo sea clínicamente útil.

El ejemplo del dossier

El Documento B reporta estas métricas para los dos grupos:

Indicador Grupo A Grupo B
Tamaño de muestra 30.000 20.000
Precisión (VPP) 86% 81%
Recall (sensibilidad) 89% 58%
FNR 11% 42%
FPR 8,5% 12%

La lectura directa: de cada 1.000 pacientes que realmente tendrán una complicación, el modelo deja pasar a 110 del Grupo A y a 420 del Grupo B. La diferencia es de 310 pacientes por cada 1.000. No es un detalle estadístico: es la diferencia entre detectar a casi todos y detectar a poco más de la mitad.

Cuidado con la exactitud

Si la variable objetivo es el percentil 85 del gasto, la clase positiva es el 15% de los casos. Un clasificador trivial que diga "sin riesgo" a todos tendría 85% de exactitud. El 88,5% del modelo es solo 3,5 puntos mejor. La exactitud global no demuestra que el modelo sea clínicamente útil.

Por qué el promedio global engaña

El Documento A reporta una sensibilidad global de 82%. El Documento B reporta 89% para el Grupo A y 58% para el Grupo B. Esas tres cifras no se pueden reconciliar sin conocer la prevalencia de cada grupo y la matriz de confusión completa. Si ambos grupos tuvieran la misma prevalencia, el promedio ponderado por tamaño sería 76,6%, no 82%.

Eso no significa que el 82% sea falso. Significa que el reporte no da la información necesaria para verificarlo. Un auditor debe pedir la matriz de confusión, la prevalencia por grupo y los intervalos de confianza antes de aceptar un promedio global.

Regla de auditoría

Ninguna métrica global reemplaza una métrica desagregada. Si el sistema decide acceso a un servicio de salud, el desempeño por subgrupo es parte del desempeño, no un anexo.

Checklist para leer el dossier

  1. ¿Cuál es la variable objetivo? Si es un proxy, pregúntate qué mide realmente y a quién deja fuera.
  2. ¿Cuál es la clase positiva? En este caso, el paciente que tendrá una complicación.
  3. ¿Cuál es el umbral? El puntaje menor a 40 no es una propiedad del modelo; es una decisión operativa.
  4. ¿Hay matriz de confusión? Sin TP, FP, FN y TN no se puede reconstruir el resto.
  5. ¿Hay prevalencia por grupo? Sin ella, el FNR no se convierte en número absoluto de pacientes.
  6. ¿Hay métricas desagregadas? El promedio global puede ocultar una brecha clínicamente inaceptable.
  7. ¿Hay intervalos de confianza? Una diferencia entre grupos puede ser real o ruido; el reporte debe permitir juzgarlo.
  8. ¿Qué error importa más en este contexto? En un tamizaje de urgencias, el falso negativo es el error que más daño hace.
