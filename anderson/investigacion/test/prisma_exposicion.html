ProtocolResearch Question · PICOS Framework

Research question

RQ · Among locally runnable LLMs (consumer-hardware feasibility constraint), how has coding and software-engineering benchmark performance evolved across model release dates from 2023 to 2026, and how large is the remaining gap to the best closed proprietary models?

P

Population

Evaluation studies of LLMs for code tasks whose models are locally runnable: Q4_K_M weights + KV cache fully resident at ≥ 15–20 tok/s. Primary 16 GB VRAM · envelope 24 GB · sensitivity 8 GB · Apple unified ≤ 48 GB.

I

Intervention

Open-weight code LLMs across release generations, 2023–2026 (e.g., CodeLlama → Qwen2.5-Coder → Qwen3-Coder): release date is the exposure whose slope is estimated.

C

Comparator

Two reference lines: the closed proprietary frontier (envelope-of-best per benchmark and date) and an all-open-weight, feasibility-blind line. Outcome of comparison: the residual feasibility penalty.

O

Outcomes

Pre-specified set: HumanEval(+), MBPP(+), LiveCodeBench, BigCodeBench (primary, code generation); SWE-bench Verified / Pro (secondary, software engineering). Normalized 0–100.

S

Study design

Systematic review per PRISMA 2020 with quantitative synthesis (mixed-effects meta-regression); evaluation studies 2023–2026 (codegen), 2024–2026 (SWE); English; cutoff ≈ July 2026.

scope.txt §2–§5, §10 · OSF pre-registered · dual screeningSecondary RQ · size of the gap to the closed frontier
ProtocolComparison Design · Synthesis Model

Three-line comparison design

The gap decomposes into the already-studied open-vs-closed difference plus the feasibility penalty, which is this review's contribution.

01Feasible-local set

Population under study: ≤ 24 GB VRAM / ≤ 48 GB unified memory, Q4_K_M floor (e.g., Qwen2.5-Coder 7–32B, Llama 3.1 8B, Gemma 3, Phi-4).

02All open-weight, feasibility-blind

Includes data-center-scale open models (e.g., DeepSeek 671B MoE), the line that public hubs already track.

03Closed proprietary frontier

Best closed model per benchmark; anchored by an envelope-of-best rule at each date, with no composite black-box index.

Quantitative synthesis

Mixed-effects meta-regression on 0–100 normalized scores. Predictors: release date (the headline slope), log-parameters, hardware band (8/16/24 GB), benchmark family. Random effects clustered by model and benchmark; cluster-robust variance.

Sensitivity analyses

Independently-verified scores only · contamination-resistant benchmarks only (LiveCodeBench, SWE-bench vs saturated HumanEval/MBPP) · per hardware band.

DesignEvidence Architecture · Data Sources

How the two evidence streams combine

01PRISMA corpus (literature-first)

Screened studies evaluating ≥ 1 feasible-local model on ≥ 1 pre-specified benchmark. From each we extract model × benchmark × score, tagged with provenance: source type, self-reported vs independently run, contamination resistance.

02Benchmark leaderboards (data sources, gray-lit appendix)

Epoch AI Benchmarking Hub CSV (primary) · SWE-bench Verified official leaderboard · LiveBench snapshots · EvalPlus leaderboard. Secondary cross-checks: LLM Stats, Artificial Analysis. Not screened as studies; they supplement and verify extractions.

Merged dataset → meta-regression

Both streams merge into the quantitative synthesis. The headline parameter is the release-date slope, the speed at which locally runnable capability improves. The gap metric is the envelope-of-best distance to the closed frontier, per benchmark and date.

Risk of bias (5-item tailored appraisal)

Independent run vs self-reported · harness / version transparency · contamination-resistance · sample / compute adequacy · reporting completeness. Quality flags feed the pre-specified sensitivity analyses.

INTERIM CONCLUSION · Search and screening are complete for the three executed databases, and the pipeline is reproducible end to end. The 118-study corpus is large enough to move into co-review and extraction. One coverage caveat deserves emphasis: feasible-local models are rarely evaluated on SWE-bench. The evaluations that do exist come mostly from agent-scaffold papers testing large or closed models. That asymmetry is a finding, and the synthesis will report it as one.
