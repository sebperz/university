# Nombres — ronda de pronunciación

**Fecha:** 21/10/2026
**Estado:** exploración. No reemplaza la decisión de `NOMBRE.md`.

## El diagnóstico

`sebperz` falla en el único test que no se puede compensar con diseño: **no se puede decir**.

- Al leerlo, duda: ¿"seb-perz", "seb-pers", "seb-pérez"?
- Al oírlo, hay que dictarlo: "perz, con z".
- Al buscarlo, el resultado es correcto, pero nadie llega ahí sin que se lo escribas.

Un nombre que necesita explicación cobra un impuesto en cada presentación: en un podcast, en una charla, en una entrevista, en un mensaje de voz. La marca visible no puede depender de una aclaración.

**Regla de esta ronda:** primero se dice, después se escribe, después se busca. Si falla el primero, no importa lo demás.

## Los tres tests

| Test | Cómo se hace | Qué falla |
|---|---|---|
| **Llamada** | Decile el nombre a alguien por teléfono. Que lo escriba sin preguntar. | Si duda o pide repetir, el nombre no sirve para recomendar. |
| **Mesa** | Mostralo escrito una vez. Pedile que lo repita diez minutos después. | Si lo recuerda mal, no se fija. |
| **Buscador** | Escribilo en Google, GitHub, YouTube y X. | Si aparecen diez homónimos o una marca más grande, no es tuyo. |

### Lo que muestra la tabla

`sebperezdev` es el único que pasa los tres tests y está libre en los cinco lugares que importan. No es el nombre más elegante; es el que menos fricción genera.

`perezdev` y `sebasdev` suenan mejor, pero están ocupados. Un nombre perfecto que ya es de otro no es una opción.

## Ruta B — nombre conceptual para el proyecto

Estos nombres no son para la persona. Son para el paraguas: newsletter, comunidad, curso, repositorio. Ahí sí conviene un nombre propio, porque se puede retirar sin arrastrar la marca personal.

Todos se pronuncian. El problema de esta ruta es otro: **casi todas las palabras comunes ya están tomadas en GitHub, YouTube y X**. El dominio `.dev` suele estar libre; el handle no.

## Recomendación

**Para la persona: `sebperezdev`.**

- Se dice una vez y se escribe solo: "Seb Pérez Dev".
- Está libre en GitHub, YouTube, X, `.com` y `.dev` (verificado hoy).
- Conserva el "Seb" que ya tiene algo de historia, y agrega el apellido completo, que es lo que faltaba para que se entendiera.
- El nombre visible sigue siendo **Sebastián Pérez**. `sebperezdev` es solo la llave.

**Si la formalidad importa más que la brevedad:** `sebastianperezdev`. Es el mismo nombre, sin abreviar. Cuesta cinco caracteres más en cada perfil.

**Si el proyecto necesita un paraguas propio:** `Puerto` es el mejor equilibrio entre pronunciación, metáfora y disponibilidad de dominio. `Fuente Primaria` es el mejor nombre de newsletter; `Clave Foránea`, el mejor de una serie técnica. Ninguno debería reemplazar el nombre de la persona.

**Lo que no haría:** elegir un nombre porque el dominio está libre. Casi todos los `.dev` de esta lista están libres; el cuello de botella son los handles y la memoria de la gente.

## Qué verificar antes de pagar

1. **Registrador, no solo RDAP.** Un 404 en RDAP dice que no hay registro; no dice que el dominio sea estándar. Puede estar reservado o tener precio premium.
2. **Handles a mano.** GitHub y YouTube devuelven 404 de forma confiable. X a veces devuelve 200 para cuentas vacías o suspendidas. Abrir cada perfil y mirar.
3. **Marca registrada.** Sobre todo `Puerto`, `Nexo` y `Pacífico`, que son palabras muy usadas.
4. **Prueba de voz.** Grabá un audio de diez segundos diciendo el nombre y pasalo por un transcriptor. Si el transcriptor escribe otra cosa, un humano también.
5. **Prueba de cinco personas.** Decí el nombre una vez. Pedí que lo escriban. Si más de una falla, descartalo.

## Descartados rápido

- **`sebperz`**: no se pronuncia. Puede quedar como alias o redirección, nunca como marca visible.
- **`sebperez`**: es de otra persona desde 2009 en X y 2014 en GitHub.
- **`perezdev`, `sebasdev`**: buenos nombres, ocupados en las tres redes.
- **`sebastianperez`**: tomado y con miles de homónimos.
- **`backendenespanol`, `sistemasenespanol`, `ingenieriaenpublico`**: descriptivos; atan el nombre al nicho y al idioma. Sirven de bio, no de marca.
- **`pacifico`, `mandarina`, `pinyin`, `trilingue`**: pronunciables, pero empujan la marca hacia "China" o "idiomas", que es el wrapper que puede cambiar.
